Probe — verified
Asks the gateway for every part number of this AC and writes only the ones that exist, then marks the AC discovered. The same probing the Python app did; a minute or two per AC.
Manual range — instant, unverified
Writes the part numbers as pending for the fleet to sweep, without asking the gateway. Existing rows are never touched. A wrong number becomes a sweep that finds nothing.

Collection

Collect puts the part(s) back in the shared queue — whichever device picks them up next sweeps them; a part another device is running right now is left alone. Sweep now does the request here instead, over the same direct HTTP route the collector uses (gateway-vha …/get-eroll-data-2003), with the same claim and completion bookkeeping and with the same AIMD throttle.
